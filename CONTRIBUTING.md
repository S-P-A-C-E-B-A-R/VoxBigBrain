# Contributing

Issues and pull requests are welcome. VoxBigBrain is experimental and vibecoded, so keep changes focused and explain the behavior they change.

- Never commit secrets, `.env`, certificates, private keys, tokens, or captured audio.
- Include a concise test description for changes affecting audio, VAD, STT, realtime behavior, networking, or tool execution.
- Avoid unrelated refactors in a focused fix.
- Contributions are submitted under the repository's PolyForm Noncommercial License 1.0.0 unless a contributor agreement is introduced later.
